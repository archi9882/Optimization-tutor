# Optimization Tutor：最佳化演算法圖鑑

一個互動式的最佳化演算法學習網站。目錄收錄 59 種跨領域常用的演算法，每一種都依同一個結構整理：

1. **定義**：數學形式、假設、收斂性，推導分層收合
2. **應用場景**：跨領域的實際例子，包括機器學習、農業、水文與地球科學反演
3. **解決什麼問題**：它補了前一個方法的哪個缺點
4. **動畫演示**：可調參數、可換測試問題、可多個演算法同場比較
5. **程式與練習**：兩個折疊區塊。「虛擬碼與示範程式」顯示的 Python 就是動畫實際執行的程式；「挖空練習」把示範程式的關鍵運算式挖掉讓你填，也可以切換成從零寫，分三層自動檢查，並把你的軌跡畫在參考解上

## 快速開始

```bash
pip install jinja2 markdown pyyaml pytest
python -m pytest -q              # 參考實作、評分器與建置的測試
python scripts/build.py --serve  # 建置到 _site/ 並開在 http://localhost:8000
```

Windows 可將 `python` 換成 `py`。網站必須透過 `http://` 開啟，直接雙擊 HTML 檔時 Pyodide 無法載入。

預設從 CDN 載入 Pyodide 與 KaTeX。若要離線或在不允許外部請求的環境使用，先用 npm 下載 `pyodide@0.27.7` 與 `katex@0.16.9` 兩個套件，解壓到 `DIR/pyodide`、`DIR/katex`，再執行 `python scripts/build.py --vendor DIR --out _site_offline`。

## 架構

```
optlab/            參考實作（純 Python、無 numpy，CPython 與 Pyodide 共用）
  problems.py      測試問題：二次碗（可調 κ 與旋轉）、Rosenbrock、Himmelblau（含殘差形式）；
                   有限制問題（施肥預算三角形／等式／土壤圓盤、兩座水庫箱型、Rosenbrock + 圓盤），
                   附 KKT 乘數與最優解（手算或以二分法求出）
  sets.py          圓盤與凸多邊形的投影、線性最小化子問題（投影梯度與 Frank-Wolfe 用）
  demos/           每種演算法一個檔案：虛擬碼 + 示範函式（頁面顯示的程式＝動畫執行的程式）
  optimizers.py    動畫用的優化器清單與參數範圍，step 函式直接取自 demos/
  lp.py            二維 LP/QP 預設問題（作物配置、施肥配方、溫室興建）與逐步執行器（渲染器 ②）
  ip.py            整數規劃：分支定界、Gomory 割平面（沿用 lp.py 的表格與樞紐）
  combo.py         組合問題實例（田區、水庫、機具）與動態規劃、Kruskal、匈牙利、2-opt、禁忌搜尋的執行器
  trace.py         執行器：產生軌跡 {xs, fs, status}
  grading.py       三層評分：單步數值 → 收斂行為 → 軌跡重合
  exercises/       每題的骨架、提示、解答與測資
  api.py           JSON 介面：建置時與瀏覽器中呼叫同一份程式
content/
  catalog.yaml     所有演算法的 metadata（首頁卡片由此產生）
  algorithms/*.md  完整頁面（frontmatter 設定動畫與練習）
site_src/          Jinja2 模板、CSS、JS（渲染器、Pyodide worker）
scripts/build.py   產生靜態網站到 _site/
tests/             pytest
```

**單一來源：** 動畫的預設畫面在建置時由 CPython 執行 `optlab` 預先算好，所以頁面打開就能看到；使用者調整參數時，改由瀏覽器中的 Pyodide 執行同一份 `optlab` 即時重算。練習題的評分器也在瀏覽器中執行，與 `pytest` 用的是同一份程式碼。

**執行安全：** Python 跑在 Web Worker 裡，學習者的程式若陷入無窮迴圈，超過 8 秒會自動終止並重啟 worker。

## 新增一種演算法

1. 在 `content/catalog.yaml` 加一筆 metadata，首頁就會出現它的卡片與骨架頁。
2. 若屬於連續二維問題，在 `optlab/` 加 step 函式並登記到 `OPTIMIZERS`，就能直接使用渲染器 ①。有限制的問題在 `problems.py` 以 `constraints`（g(x) ≤ 0 或 = 0，附梯度與 Hessian）描述，頁面用 `lab.problems` 列出可選的問題，渲染器會自動畫出不可行區域與限制邊界。LP/QP 類則在 `optlab/lp.py`（整數規劃在 `ip.py`）加執行器，頁面用 `lp:` frontmatter 與 `<!-- lp -->` 標記使用渲染器 ②；組合問題在 `optlab/combo.py` 加執行器，用 `combo:` 與 `<!-- combo -->`。
3. 寫 `content/algorithms/<id>.md`，用 `<!-- lab -->` 和 `<!-- practice -->` 標記插入動畫與練習。
4. 示範程式與虛擬碼放在 `optlab/demos/<id>.py`；練習題（骨架、提示、測資、挖空位置）放在 `optlab/exercises/<id>.py`，並登記到 `EXERCISES`。
5. 執行 `python -m pytest -q`，建置測試會檢查 id、標籤與嵌入資料是否一致。

## 用詞與數值慣例

**用詞**（頁面、目錄與介面字串一致；程式識別字不受影響）：

| 用詞 | 用在 | 例子 |
|---|---|---|
| 最佳化 | 學科與動作（optimization），台灣慣用譯名，保留 | 有限制最佳化、最佳化演算法 |
| 最優 | 數學上的最優（optimal / optimum） | 最優解、最優值、最優目標值、最優指派、最優步長、最優收斂率、最優子結構 |
| 最佳 | 只用在「目前找到最好的」：不保證最優 | 現有最佳解（incumbent）、歷史最佳（禁忌搜尋）、粒子群的群體最佳位置；另保留固定詞「最佳優先」「最佳控制」 |
| 局部最小值 | 連續函數 $f$ 的局部極小 | 牛頓法、信賴域法頁面 |
| 局部最優（解） | 組合問題中鄰域內最好的解 | 2-opt、禁忌搜尋的路線 |
| 剪枝 | 分支定界丟掉一個節點或分支 | 「上界不比現有最佳解好，剪枝」 |

**步數的兩種標準：** 動畫結果列同時列出兩個步數，頁面引用步數時一定寫明是哪一種：

- 「$f-f^*<10^{-10}$ 於第 $k$ 步」：第一個函數值與最優值差距低於門檻的迭代。無導數方法與 Nesterov 頁面用 $10^{-8}$（frontmatter 的 `lab.reach_tol`）。
- 「第 $N$ 步停止」：執行器的停止條件，梯度範數 $<10^{-10}$，或演算法自己的停止條件（單純形縮小、輪詢步長、有限制方法的外迴圈）。

**滑桿刻度**（`optlab/sliders.py`）：對數滑桿取 $[lo,hi]$ 內所有兩位有效數字的值，線性滑桿用固定的 1／2／5 × 10ᵏ 步長，整數參數只取整數。頁面「建議的實驗」引用的值都在刻度上，`tests/test_sliders.py` 會檢查。每個動畫都有「重設」按鈕，回到本頁預設的問題、參數、起點與迭代數。

## 資料來源與 AI 使用聲明

- **資料：** 全部是合成的解析測試函數與虛構的小型實例（田區座標以固定亂數種子產生；水庫入流、機具時數為手設數字；有限制最佳化頁面的施肥損失函數與水庫放水目標也是虛構的教學係數），沒有使用外部資料集。
- **AI 協作：** 網站架構、渲染器、Pyodide 整合、目錄 metadata 與各演算法頁面的初稿由 AI（Claude）撰寫。標示「AI 草稿」的頁面尚未經作者逐段審閱。頁面中的數值都是本 repo 程式實際執行的結果。
- **引用：** 目前頁面沒有引用特定文獻。加入引用前，會先查證原始出處。

| 座標下降 | SOR 對對稱正定矩陣在 0 < ω < 2 時收斂 |
| 牛頓法 | 局部二次收斂的條件（Hessian 正定且 Lipschitz 連續） |
| 高斯-牛頓 | 地震定位的 Geiger 法屬於高斯-牛頓迭代 |
| Levenberg-Marquardt | 水文模式參數校準軟體普遍採用 LM 類方法 |
| BFGS | 強凸與 Wolfe 線搜尋下的超線性收斂 |
| 信賴域法 | 全域收斂保證與接近解時的二次收斂 |
| 單純形法 | Klee–Minty 立方體讓 Dantzig 規則走過 2ⁿ 個頂點 |
| 單純形法 | Bland 規則可避免循環 |
| 對偶單純形法 | 求解器在很多問題上預設使用對偶單純形法；分支定界常以它重新求解子問題 |
| 內點法（LP） | 多項式時間複雜度；精確中心點的對偶間隙等於 m·μ |
| 內點法（LP） | 實務求解器多用原始-對偶形式；中心路徑的極限是最優面的解析中心 |
| 有效集法（QP） | 模型預測控制常以有效集法暖啟動 |
| 分支定界 | 整數規劃一般為 NP-hard；現代 MIP 求解器以分支定界搭配割平面（branch and cut）為核心 |
| 割平面 | 純 Gomory 割單獨使用時收斂慢、數值不穩定 |
| 動態規劃 | 最優性原理；Bellman-Ford、Dijkstra 與序列比對屬於動態規劃 |
| 貪婪法 | 擬陣上貪婪法保證最優；單一連結分群等同 Kruskal 過程 |
| 匈牙利演算法 | König 定理；指派問題的限制矩陣為全單模 |
| 2-opt | 平面上交叉的兩條邊換成不交叉一定更短（三角不等式論證） |
| 禁忌搜尋 | 特赦規則與禁忌期選擇的實務經驗 |
| Nelder-Mead | 平滑凸函數上收斂到非駐點的反例出自 McKinnon（本站測試重現了該函數與起始三角形，出處與參數待查證） |
| Nelder-Mead | 高維（十幾個參數以上）時單純形易退化、效果明顯變差；停滯時重新建立單純形是常見補救 |
| Nelder-Mead | 水文模式校準常以 Nelder-Mead 作為第一個嘗試（SCE-UA 內含單純形步驟） |
| Powell 法 | 原版丟掉第一個方向，方向集合可能線性相依；改丟「下降最多的方向」與定期重設方向是常見修正 |
| Powell 法 | n 維二次函數在有限輪內精確求解（本站只在二維實測：第 2 輪達到 f < 1e-8） |
| Powell 法 | 以拋物線內插（Brent 法）取代黃金分割可大幅減少一維搜尋的函數計算 |

| 障礙函數法 | 內點法是許多大型非線性規劃求解器的核心，並用於電力系統潮流最佳化；原始-對偶內點法是 LP／QP 的主流解法之一 |
